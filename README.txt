heyitssandy_ POP FOLIO website

Files:
- index.html: Main website file. It contains the HTML, CSS, and JavaScript in one file.

Upload instructions:
1. For a hosting service that accepts a ZIP upload (such as Netlify Drop), upload heyitssandy_site_upload.zip.
2. For a hosting service that asks for website files, upload index.html (or upload the folder containing index.html).
3. Open index.html locally in a browser to preview the site.

Note: The website loads Google Fonts from the internet. If offline, the browser will use fallback fonts.
